# ACAPURO — Research & Digital Direction / V2

Bilingual, static Rocket Pine research presentation. Nine chapters, plus opening and closing. No storefront mockups. No build step or environment variables required.

## Deploy
Extract the ZIP, preserving `index.html`, `styles.css`, `script.js`, and `assets/`. Open `index.html` locally or serve the folder. On Vercel select Framework Preset Other, no build command, project root (`.`) as output. Not yet deployed. EN/ES is translated in place; preference persists where localStorage is allowed. `noindex,nofollow` is intentional for a client research presentation; it is not access control.
